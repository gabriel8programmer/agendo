# Project Rules - Agendo SaaS

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## UI/UX

- Mobile-first sempre
- Layout com card centralizado
- Fundo claro (#f9fafb)
- Cards brancos com sombra leve
- Bordas arredondadas (rounded-2xl)
- UI minimalista

## Componentização

- Reutilizar componentes em /components/ui
- Evitar código duplicado

## Código

- Simples e legível
- Evitar complexidade desnecessária
- Nomear bem variáveis e funções

## MVP Rules

- NÃO adicionar features extras
- Focar apenas no essencial:
  - login
  - serviços
  - agenda
  - página pública
  - configurações

## Responsividade

- Mobile-first obrigatório
